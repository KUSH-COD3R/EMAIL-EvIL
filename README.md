# EMAIL-EvIL

A tiny Python tool to generate plus-address email aliases for inbox organization.

## Example

```bash
python3 email_aliases.py
```

Input:

```text
alex@example.com
```

Output:

```text
Generated aliases:
alex+shopping@example.com
alex+newsletters@example.com
alex+travel@example.com
alex+projects@example.com
alex+banking@example.com
```

This is a harmless inbox-management trick that works with providers that support plus-addressing.
